CSS Property Grammar Subset
===========================

This file documents the small property registry implemented by the typed-value
layer. Unknown properties and custom properties remain permissive.

color
    ::= color-value

width | height
    ::= NUMBER "0"
      | DIMENSION
      | PERCENTAGE
      | calc() | min() | max() | clamp()
      | "auto"

margin
    ::= box-value (WHITESPACE box-value){0,3}

padding
    ::= length-percentage (WHITESPACE length-percentage){0,3}

box-value
    ::= DIMENSION | PERCENTAGE | NUMBER "0" | "auto"

length-percentage
    ::= DIMENSION | PERCENTAGE | NUMBER "0"

font-size
    ::= DIMENSION | PERCENTAGE | NUMBER "0"
      | calc() | min() | max() | clamp()
      | "xx-small" | "x-small" | "small" | "medium"
      | "large" | "x-large" | "xx-large" | "xxx-large"
      | "smaller" | "larger"

opacity
    ::= NUMBER
      | PERCENTAGE

display
    ::= "block" | "inline" | "inline-block"
      | "flex" | "inline-flex"
      | "grid" | "inline-grid"
      | "flow-root" | "none" | "contents"

The registry validates only these generic property shapes. It does not perform
cascade, inheritance, shorthand expansion, unit conversion, or property-specific
value computation.
